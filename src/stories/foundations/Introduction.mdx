# Sartoria — Design System

Design system del gestionale **Sartoria su misura**.
Ispirazione _atelier italiano_: palette verde-foresta, bianco freddo,
tipografia DM Sans, radius minimo (2px), ombre sussurrate.

## Stack

- **Tailwind CSS v4** con tokens definiti in `@theme inline` dentro `globals.css`
- **Base UI** (`@base-ui/react`) per i primitivi headless
- **CVA** per le varianti dei componenti
- **DM Sans** (300/400/500) per testo, **Geist Mono** per il monospaziato

## Struttura

- **Foundations** — token visivi: colori, tipografia, spaziature, raggi, ombre
- **Components** — primitivi UI riusabili presenti in `src/components/ui/`

Apri il toolbar in alto a destra per cambiare tema **Light / Dark**.
